# Salvazion Inc.

Esta carpeta es el repo de la empresa. Ábrela como directorio de trabajo del CLI.

Antes de cambiar propósito, marca o textos que cruzan productos, lee `canon/purpose.md` y la ficha del producto. El enunciado oficial del propósito se copia tal cual. No lo reformules.

- **Salvazion** es la plataforma que restaura a la persona humana: Salvation, Health y Freedom, en salvazion.org.
- **Kaenz** es la plataforma de viajes en yate (Commute, Tour, Special Occasion). No es un operador de charter.
- **Mapucoin** es la plataforma de viajes en Chile: presupuesto, lugar, itinerario, cápsulas, gastronomía y actividades.

Cada proyecto es su propio repositorio Git y despliega solo. El código se commitea dentro de esa carpeta. Después se actualiza el puntero en este repo. No mezcles marcas, dominios ni bases de datos entre productos.

No copies secretos ni archivos `.env` a este repo.
